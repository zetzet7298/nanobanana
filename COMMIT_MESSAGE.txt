with support for batch generation, image editing, and AI-powered analysis.

- Image generation with grok-imagine-1.0 and grok-imagine-1.0-fast models
- Batch generation support (1-10 images per request with fast model)
- Image editing with grok-imagine-1.0-edit model
- Image analysis with Grok chat models (grok-3, grok-4, grok-4.1, etc.)
- Configurable via environment variables (GROK_API_BASE_URL, GROK_API_KEY, etc.)
